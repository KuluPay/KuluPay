# kulupay init

Initialize KuluPay in your project. This creates a `kulupay.json` registry, a `lib/pay.ts` server config using your selected database adapter, a `lib/pay-client.ts` client config, and the framework route file.

## Usage

```bash
npx kulupay init
```

## What It Does

1. Prompts for framework and routing setup (Next.js App/Pages Router, Express, Hono, or Elysia)
2. Prompts for database adapter (Memory, PostgreSQL, MySQL, SQLite, Prisma, Drizzle)
3. Generates `lib/pay.ts` with the correct adapter import and a placeholder `database`
4. Generates `lib/pay-client.ts`
5. Creates the framework API route file
6. Creates `kulupay.json`

The CLI does **not** ask for secrets or database URLs. After init, it prints the packages and environment variables you need to set.

## Generated File

```ts title="lib/pay.ts"
import { kuluPay } from "@kulupay/kulupay";
import { pg } from "@kulupay/adapter-sql";
import { Pool } from "pg";

const database = pg(
  new Pool({ connectionString: process.env.DATABASE_URL! }),
);

export const pay = kuluPay({
  database,
  providers: [],
  baseURL: process.env.KULUPAY_URL ?? "http://localhost:3000",
  debug: true,
});
```

## Options

| Option | Description |
| --- | --- |
| `-c, --cwd <cwd>` | Working directory (default: current directory) |
| `-f, --framework <framework>` | Framework: `nextjs`, `express`, `hono`, or `elysia` |
| `-d, --database <database>` | Database: `memory`, `postgres`, `mysql`, `sqlite`, `prisma`, or `drizzle` |
| `--baseURL <baseURL>` | App base URL |
| `-y, --yes` | Skip confirmation prompts |

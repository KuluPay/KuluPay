# Checkout UI

KuluPay provides a **React checkout component** and a **headless hook** that handle the entire onchain payment flow — wallet connection via AppKit, transaction submission, and on-chain confirmation polling.

## Architecture

```
@kulupay/kulupay/checkout           ← shared types + utilities (vanilla TS)
@kulupay/kulupay/checkout/react     ← React component + headless hook
```

The React package exports:
- `KuluPayCheckout` — prebuilt checkout card UI
- `useKuluPayCheckout` — headless hook for building your own UI
- `CheckoutIntentData`, `PayClientLike` — types
- `formatAmount`, `formatTokenAmount`, `shortenAddress`, `timeRemaining` — utilities

<Callout type="info">
  Wallet connection uses [Reown AppKit](https://reown.com/appkit) — supports MetaMask, Coinbase, Phantom, Trust, Rabby, Rainbow, OKX, TronLink, and any WalletConnect-compatible wallet.
</Callout>

## Prebuilt Component

Use `KuluPayCheckout` for a ready-made checkout card with inline styles — no CSS framework required:

```tsx title="app/checkout/page.tsx"
"use client";

import { use, Suspense } from "react";
import { KuluPayCheckout } from "@kulupay/kulupay/checkout/react";
import { payClient } from "@/lib/pay-client";

function CheckoutContent({ searchParams }: { searchParams: Promise<{ intentId?: string; clientSecret?: string }> }) {
  const params = use(searchParams);

  if (!params.intentId || !params.clientSecret) {
    return <div>Missing parameters</div>;
  }

  return (
    <KuluPayCheckout
      client={payClient}
      intentId={params.intentId}
      clientSecret={params.clientSecret}
      onSuccess={(txHash) => console.log("Paid!", txHash)}
      onError={(err) => console.error("Payment failed", err)}
    />
  );
}

export default function CheckoutRoute({ searchParams }: { searchParams: Promise<{ intentId?: string; clientSecret?: string }> }) {
  return (
    <Suspense fallback={<div>Loading...</div>}>
      <CheckoutContent searchParams={searchParams} />
    </Suspense>
  );
}
```

### Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `client` | `PayClientLike` | Yes | Pay client instance from `createPayClient()` |
| `intentId` | `string` | Yes | Payment intent ID from `createIntent` |
| `clientSecret` | `string` | Yes | Client secret from the intent response |
| `onSuccess` | `(txHash: string) => void` | No | Called when payment is confirmed on-chain |
| `onError` | `(error: Error) => void` | No | Called on payment failure |
| `className` | `string` | No | CSS class applied to the checkout card |

### UI States

The component renders the following states automatically:

- **Loading** — while the intent is being fetched
- **Error** — if the intent fails to load or payment fails
- **Expired** — if the payment link has expired
- **Success** — when the transaction is confirmed on-chain
- **Ready** — shows amount, connect wallet button (via AppKit), and pay button

## Headless Hook

Use `useKuluPayCheckout` to build your own UI while keeping all the payment logic:

```tsx title="app/custom-checkout/page.tsx"
"use client";

import { useKuluPayCheckout } from "@kulupay/kulupay/checkout/react";
import { KuluPayConnectButton } from "@kulupay/kulupay/appkit-react";
import { payClient } from "@/lib/pay-client";
import { useSearchParams } from "next/navigation";

export default function CustomCheckout() {
  const searchParams = useSearchParams();
  const intentId = searchParams.get("intentId")!;
  const clientSecret = searchParams.get("clientSecret")!;

  const {
    intent,
    status,
    error,
    connected,
    address,
    txHash,
    connect,
    pay,
    disconnect,
    appKitLoading,
  } = useKuluPayCheckout({
    client: payClient,
    intentId,
    clientSecret,
    onSuccess: (hash) => console.log("Paid!", hash),
    onError: (err) => console.error("Failed", err),
  });

  if (status === "loading" || appKitLoading) return <div>Loading...</div>;
  if (status === "error" || !intent) return <div>{error || "Failed to load"}</div>;
  if (status === "expired") return <div>Payment link expired</div>;
  if (status === "success") return <div>Payment complete!</div>;

  const amount = `${(intent.amount / 100).toFixed(2)} ${intent.currency}`;

  return (
    <div>
      <h1>Pay {amount}</h1>
      {intent.description && <p>{intent.description}</p>}

      {connected && address ? (
        <>
          <p>Connected: {address}</p>
          <button onClick={pay} disabled={status === "sending"}>
            {status === "sending" ? "Confirming..." : `Pay ${amount}`}
          </button>
          <button onClick={disconnect}>Disconnect</button>
        </>
      ) : (
        <KuluPayConnectButton
          chains={intent.chainConfig ? [intent.chainConfig] : []}
          label="Connect wallet"
        />
      )}

      {error && <p style={{ color: "red" }}>{error}</p>}
    </div>
  );
}
```

### Hook Return Values

| Field | Type | Description |
|-------|------|-------------|
| `intent` | `CheckoutIntentData \| null` | Full intent data from `checkoutIntent` API |
| `status` | `Status` | `"loading" \| "ready" \| "connecting" \| "sending" \| "confirming" \| "success" \| "error" \| "expired"` |
| `error` | `string \| null` | Error message if any |
| `txHash` | `string \| null` | Transaction hash after submission |
| `connected` | `boolean` | Whether a wallet is connected |
| `address` | `string \| null` | Connected wallet address |
| `connect` | `() => Promise<void>` | Connect to wallet |
| `pay` | `() => Promise<void>` | Send payment and poll for confirmation |
| `disconnect` | `() => void` | Disconnect wallet |
| `appKitLoading` | `boolean` | Whether AppKit is initializing |

## The Payment Flow

1. **Client** calls `createIntent` → receives `intentId` and `clientSecret`
2. **Client** navigates to checkout page with those params
3. **Hook** loads the intent via `checkoutIntent` API
4. **Hook** initializes AppKit with the chain config from the intent
5. **User** clicks "Connect wallet" → AppKit opens wallet selection modal
6. **User** connects their wallet (MetaMask, TronLink, WalletConnect, etc.)
7. **User** clicks "Pay" → hook calls `sendPayment()` → wallet prompts transaction
8. **Hook** polls `verifyIntent` every 3 seconds until status is `succeeded`/`failed`
9. **UI** updates to show success/failure state

## Server Configuration: `checkoutUrl`

Set `checkoutUrl` on the server to give clients a ready-made redirect URL:

```ts title="lib/pay.ts"
import { kuluPay } from "@kulupay/kulupay";

export const pay = kuluPay({
  database: drizzleAdapter(db, { provider: "pg" }),
  // ... providers, plugins, etc.

  // When set, the createIntent response includes a `checkoutUrl` field
  // with intentId and clientSecret already embedded.
  checkoutUrl: "/checkout?intentId={intentId}&clientSecret={clientSecret}",
});
```

### Client: Redirect After Intent Creation

```tsx title="app/page.tsx"
"use client";
import { payClient } from "@/lib/pay-client";
import { useRouter } from "next/navigation";

export default function Home() {
  const router = useRouter();

  const handlePay = async () => {
    const result = await payClient.createIntent({
      body: {
        amount: 1000,
        currency: "usd",
        providerId: "ethereum",
        token: "USDC",
      },
    });

    if (result?.data?.checkoutUrl) {
      router.push(result.data.checkoutUrl);
    } else if (result?.data?.id && result?.data?.clientSecret) {
      router.push(`/checkout?intentId=${result.data.id}&clientSecret=${result.data.clientSecret}`);
    }
  };

  return <button onClick={handlePay}>Pay $10.00</button>;
}
```

<Callout type="info">
  `checkoutUrl` is optional. If not configured on the server, the field is `undefined` and the client builds the URL manually from `id` and `clientSecret`.
</Callout>

## Fully Custom Checkout (No Hook)

If you want complete control — your own wallet library, your own UI, no AppKit — you can build the checkout entirely yourself using the KuluPay API directly:

```tsx title="app/custom-checkout/page.tsx"
"use client";
import { useEffect, useState } from "react";
import { payClient } from "@/lib/pay-client";
import { useSearchParams } from "next/navigation";

export default function CustomCheckout() {
  const searchParams = useSearchParams();
  const intentId = searchParams.get("intentId")!;
  const clientSecret = searchParams.get("clientSecret")!;
  const [intent, setIntent] = useState<any>(null);
  const [txHash, setTxHash] = useState<string | null>(null);
  const [status, setStatus] = useState<string>("pending");

  useEffect(() => {
    payClient.checkoutIntent({
      intentId,
      clientSecret,
    }).then((res) => setIntent(res.data));
  }, [intentId, clientSecret]);

  const handlePay = async () => {
    const raw = intent.raw;
    // Use viem, ethers, tronweb, or any wallet library
    const hash = await window.ethereum.request({
      method: "eth_sendTransaction",
      params: [{
        to: raw.to,
        value: raw.value,
        data: raw.data,
      }],
    });
    setTxHash(hash);

    await payClient.confirmIntent({
      body: { intentId, txHash: hash, clientSecret },
    });

    const poll = setInterval(async () => {
      const res = await payClient.verifyIntent({
        intentId,
        clientSecret,
      });
      setStatus(res.data.status);
      if (res.data.status === "succeeded" || res.data.status === "failed") {
        clearInterval(poll);
      }
    }, 5000);
  };

  if (!intent) return <div>Loading...</div>;

  return (
    <div>
      <h1>Pay {intent.amount / 100} {intent.currency.toUpperCase()}</h1>
      <p>Token: {intent.raw.tokenSymbol}</p>
      <button onClick={handlePay} disabled={!!txHash}>
        {txHash ? "Confirming..." : "Pay Now"}
      </button>
      {txHash && <p>TX: {txHash}</p>}
      <p>Status: {status}</p>
    </div>
  );
}
```

### Key API Endpoints

| Endpoint | Method | Auth | Purpose |
|----------|--------|------|---------|
| `/create-intent` | POST | Session | Creates the payment intent, returns `raw` tx data |
| `/checkout-intent` | GET | clientSecret | Loads full intent data for checkout rendering |
| `/confirm-intent` | POST | clientSecret | Submits the tx hash after user sends the transaction |
| `/verify-intent` | GET | clientSecret | Polls for on-chain confirmation status |

<Callout type="warn" title="Important">
  When building a fully custom checkout without the hook, you are responsible for:
  - Wallet connection and network switching
  - Balance checks before sending transactions
  - Error handling for rejected transactions
  - Polling for confirmation status

  The `useKuluPayCheckout` hook and `KuluPayCheckout` component handle all of this automatically.
</Callout>

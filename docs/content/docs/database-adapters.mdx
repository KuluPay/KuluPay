# Database Adapters

KuluPay is database-agnostic. You bring your own database client and pass it through an adapter. This mirrors the [Better Auth](https://www.better-auth.com/) adapter pattern and avoids creating duplicate database connections.

## Adapter Packages

| Adapter | Package | Supported clients |
|---------|---------|-------------------|
| SQL | `@kulupay/adapter-sql` | `pg.Pool`, `mysql2` connection, `better-sqlite3` |
| Drizzle | `@kulupay/adapter-drizzle` | `drizzle-orm` instances |
| Prisma | `@kulupay/adapter-prisma` | `PrismaClient` |

## PostgreSQL

```bash
pnpm add @kulupay/adapter-sql pg
```

```ts title="lib/pay.ts"
import { kuluPay } from "@kulupay/kulupay";
import { pg } from "@kulupay/adapter-sql";
import { Pool } from "pg";

const pool = new Pool({ connectionString: process.env.DATABASE_URL! });

export const pay = kuluPay({
  database: pg(pool),
  providers: [],
});
```

## MySQL

```bash
pnpm add @kulupay/adapter-sql mysql2
```

```ts title="lib/pay.ts"
import { kuluPay } from "@kulupay/kulupay";
import { mysql } from "@kulupay/adapter-sql";
import mysql2 from "mysql2/promise";

const connection = await mysql2.createConnection(process.env.DATABASE_URL!);

export const pay = kuluPay({
  database: mysql(connection),
  providers: [],
});
```

## SQLite

```bash
pnpm add @kulupay/adapter-sql better-sqlite3
```

```ts title="lib/pay.ts"
import { kuluPay } from "@kulupay/kulupay";
import { sqlite } from "@kulupay/adapter-sql";
import Database from "better-sqlite3";

const db = new Database("kulupay.db");

export const pay = kuluPay({
  database: sqlite(db),
  providers: [],
});
```

## Drizzle

```bash
pnpm add @kulupay/adapter-drizzle drizzle-orm
```

```ts title="lib/pay.ts"
import { kuluPay } from "@kulupay/kulupay";
import { drizzleAdapter } from "@kulupay/adapter-drizzle";
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";

const db = drizzle(new Pool({ connectionString: process.env.DATABASE_URL! }));

export const pay = kuluPay({
  database: drizzleAdapter(db, { provider: "pg" }),
  providers: [],
});
```

## Prisma

```bash
pnpm add @kulupay/adapter-prisma @prisma/client
```

```ts title="lib/pay.ts"
import { kuluPay } from "@kulupay/kulupay";
import { prismaAdapter } from "@kulupay/adapter-prisma";
import { PrismaClient } from "@prisma/client";

const prisma = new PrismaClient();

export const pay = kuluPay({
  database: prismaAdapter(prisma, { provider: "postgresql" }),
  providers: [],
});
```

## Memory (for testing)

```ts title="lib/pay.ts"
import { kuluPay } from "@kulupay/kulupay";
import { createMemoryDriver } from "@farming-labs/orm";

export const pay = kuluPay({
  database: createMemoryDriver(),
  providers: [],
});
```

## Reusing Existing Clients

The main advantage of adapters is that you can reuse the same database client your application already uses:

```ts
// Your app already has a Prisma client
import { prisma } from "./prisma";

export const pay = kuluPay({
  database: prismaAdapter(prisma, { provider: "postgresql" }),
  providers: [],
});
```

This keeps KuluPay out of your database connection pool and makes migrations simpler.

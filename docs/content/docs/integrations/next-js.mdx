# Next.js Integration

KuluPay provides a first-class integration for Next.js App Router. You can expose a single API route for all payment operations, then use the React client to collect payments from any provider.

This guide sets up:

- A single `/api/pay/[...kulupay]` route
- Server-side providers: Stripe, EVM crypto, Tron crypto
- A React checkout UI that works with all providers

---

## 1. Install dependencies

```bash
npm install @kulupay/kulupay @kulupay/core stripe pg
```

Optional peer dependencies (only install what you use):

```bash
npm install viem tronweb
```

---

## 2. Configure KuluPay

Create `lib/pay.ts` with your plugins. The example below wires the onchain plugin for EVM and Tron payments.

```ts title="lib/pay.ts"
import { kuluPay } from "@kulupay/kulupay";
import { onchain } from "@kulupay/onchain";
import { drizzleAdapter } from "@kulupay/adapter-drizzle";
import { db } from "./db";

export const pay = kuluPay({
  database: drizzleAdapter(db, { provider: "pg" }),
  plugins: [
    onchain({
      ethereum: {
        recipientAddress: process.env.NEXT_PUBLIC_EVM_RECIPIENT_ADDRESS as `0x${string}`,
        tokens: ["USDC", "USDT"],
        testnet: true,
      },
      base: {
        recipientAddress: process.env.NEXT_PUBLIC_EVM_RECIPIENT_ADDRESS as `0x${string}`,
        tokens: ["USDC", "USDT"],
        testnet: true,
      },
      tron: {
        recipientAddress: process.env.NEXT_PUBLIC_TRON_RECIPIENT_ADDRESS!,
        tokens: ["USDT"],
        testnet: true,
      },
    }),
  ],
  baseURL: process.env.KULUPAY_URL ?? "http://localhost:3000",
  checkoutUrl: "/checkout?intentId={intentId}&clientSecret={clientSecret}",
  auth: {
    getSession: async (req) => yourAuthSession(req),
  },
});
```

For Stripe, use the `stripe` provider plugin and pass your `apiKey` and `webhookSecret`.

## 3. Add the API route

Create the catch-all route that handles every KuluPay request.

```ts title="app/api/pay/[...kulupay]/route.ts"
import { toNextJsHandler } from "@kulupay/kulupay/next-js";
import { pay } from "@/lib/pay";

export const { GET, POST, PUT, PATCH, DELETE } = toNextJsHandler(pay);
```

---

## 4. Set up the client

Create `lib/pay-client.ts` with `createPayClient` and the `onchainClient` plugin.

```ts title="lib/pay-client.ts"
import { createPayClient } from "@kulupay/kulupay/client";
import { onchainClient } from "@kulupay/onchain/client";

export const payClient = createPayClient({
  baseURL: process.env.NEXT_PUBLIC_KULUPAY_URL ?? "http://localhost:3000",
  plugins: [
    onchainClient({
      walletConnectProjectId: process.env.NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID!,
    }),
  ],
});
```

## 5. Build the checkout UI

Create a page that calls `createIntent` and redirects to the checkout page.

```tsx title="app/page.tsx"
"use client";

import { useState } from "react";
import { useRouter } from "next/navigation";
import { payClient } from "@/lib/pay-client";

export default function Home() {
  const router = useRouter();
  const [amount, setAmount] = useState("10.00");
  const [currency, setCurrency] = useState("USD");
  const [providerId, setProviderId] = useState("ethereum-usdc");
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const handlePay = async () => {
    setError(null);
    setLoading(true);

    try {
      const cents = Math.round(parseFloat(amount) * 100);
      if (!cents || cents <= 0) throw new Error("Enter a valid amount");

      const [chain, token] = providerId.split("-");
      const result = await payClient.createIntent({
        body: {
          amount: cents,
          currency: currency.toLowerCase(),
          providerId: chain,
          token: token?.toUpperCase(),
          type: "one_time",
        },
      });

      if (result?.data?.id && result?.data?.clientSecret) {
        const url = result.data.checkoutUrl
          ?? `/checkout?intentId=${result.data.id}&clientSecret=${result.data.clientSecret}`;
        router.push(url);
      } else {
        setError(result?.error?.message || "Missing id or clientSecret in response");
      }
    } catch (err: any) {
      setError(err?.message || "Something went wrong");
    } finally {
      setLoading(false);
    }
  };

  return (
    <main style={{ padding: 24, fontFamily: "sans-serif", maxWidth: 600 }}>
      <h1>KuluPay Demo</h1>
      <input value={amount} onChange={(e) => setAmount(e.target.value)} />
      <select value={providerId} onChange={(e) => setProviderId(e.target.value)}>
        <option value="ethereum-usdc">Ethereum USDC</option>
        <option value="base-usdt">Base USDT</option>
        <option value="tron-usdt">Tron USDT</option>
      </select>
      <button onClick={handlePay} disabled={loading}>
        {loading ? "Creating..." : `Pay ${amount} ${currency}`}
      </button>
      {error && <p style={{ color: "red" }}>{error}</p>}
    </main>
  );
}
```

Then create the checkout page:

```tsx title="app/checkout/page.tsx"
"use client";

import { useSearchParams } from "next/navigation";
import { KuluPayCheckout } from "@kulupay/kulupay/checkout/react";
import { payClient } from "@/lib/pay-client";

export default function Checkout() {
  const searchParams = useSearchParams();
  const intentId = searchParams.get("intentId");
  const clientSecret = searchParams.get("clientSecret");

  if (!intentId || !clientSecret) {
    return <p>Missing intentId or clientSecret</p>;
  }

  return (
    <div style={{ display: "grid", placeItems: "center", minHeight: "100vh" }}>
      <KuluPayCheckout
        client={payClient}
        intentId={intentId}
        clientSecret={clientSecret}
        onSuccess={(txHash) => console.log("Paid:", txHash)}
        onError={(err) => console.error("Failed:", err)}
      />
    </div>
  );
}
```

```bash
# Refund keys (server-side only)
EVM_REFUND_PRIVATE_KEY=
TRON_REFUND_PRIVATE_KEY=
```

<Callout type="warn" title="Keep refund keys private">
  `EVM_REFUND_PRIVATE_KEY` and `TRON_REFUND_PRIVATE_KEY` must never be exposed to the browser. Use server-only environment variables.
</Callout>

## 7. Run the dev server

```bash
npm run dev
```

Open `http://localhost:3000`, pick a payment method, create an intent, and confirm.

---

## How it works

1. `payClient.createIntent()` calls `/api/pay/create-intent` and returns `id`, `clientSecret`, and `checkoutUrl`.
2. The app redirects to `/checkout?intentId=...&clientSecret=...`.
3. `KuluPayCheckout` loads the intent, initializes AppKit from `chainConfig`, and prompts the user to connect a wallet.
4. The user clicks **Pay** — the onchain client signs and broadcasts the transaction, then submits the hash via `confirmIntent`.
5. The hook polls `verifyIntent` until the payment is `succeeded` or `failed`.

For Stripe, the flow is similar: create an intent, mount the Stripe Payment Element with `clientSecret`, and confirm via Stripe.js.

## Pages Router

If you use the older Pages Router, create `pages/api/pay/[...kulupay].ts`:

```ts
import { toNextJsHandler } from "@kulupay/kulupay/next-js";
import { pay } from "@/lib/pay";

export default async function handler(req: Request) {
  const { handler: payHandler } = toNextJsHandler(pay);
  return payHandler(req);
}
```

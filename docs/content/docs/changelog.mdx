# Changelog

## v0.0.9

- `@kulupay/kulupay` — full SDK with client, server, React bindings, and checkout
- `@kulupay/cli` — provider scaffolding with auto-install peer dependencies
- Added `useKuluPayCheckout` headless hook for custom React UI
- CLI `add-provider onchain` installs `viem` and `tronweb` automatically

## v0.0.7

- `@kulupay/core` — core payment providers for Stripe, Chapa, PayPal, EVM, and Tron
- Database adapters and webhook signature verification
- Type-safe error codes and intent lifecycle

## v0.0.6

- New Fumadocs documentation site
